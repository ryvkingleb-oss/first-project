# Xiaomi TV Box S 3rd Gen — кастомизация Google TV

Приставка в домашней сети: **`192.168.10.139`**. Cloud Agent (этот чат в облаке) **не может** достучаться до частного IP — команды ADB нужно запускать **на Mac в той же Wi‑Fi**, где стоит бокс (`Air-Gleb`).

Цель: убрать рекламный домашний экран Google TV и поставить **Projectivy Launcher**.

## Один раз на Mac

```bash
brew install android-platform-tools   # если adb ещё нет
cd xiaomi-tv-box
chmod +x tvbox.sh
```

На ТВ: **Настройки → Система → О устройстве** — 7 раз по номеру сборки. Затем **Параметры разработчика**:

1. Включить **Отладка по USB** и **Беспроводная отладка**
2. Открыть **Беспроводная отладка** — там IP и **порт подключения** (не путать с портом сопряжения)
3. Если Mac ещё не спарен: **Подключить устройство с помощью кода** → на Mac:

```bash
./tvbox.sh pair 192.168.10.139:ПОРТ_СОПРЯЖЕНИЯ КОД
./tvbox.sh connect 192.168.10.139:ПОРТ_ПОДКЛЮЧЕНИЯ
```

Порты после перезагрузки ТВ часто меняются. Прошлые значения: connect `45811`, pair `38409` (уже могли смениться).

## Сделать кастомизацию

```bash
./tvbox.sh customize
```

Скрипт:

1. Подключается по ADB
2. Если Projectivy нет — ставит официальный APK с [GitHub releases](https://github.com/spocky/miproja1/releases)
3. Назначает его домашним экраном
4. Отключает стоковый лаунчер Google TV (`launcherx` + `setupwraith`)

Проверка:

```bash
./tvbox.sh status
```

Кнопка Home на пульте должна открывать Projectivy.

## Вернуть Google TV

```bash
./tvbox.sh revert
adb reboot
```

## Почему не из облака

`192.168.10.139` — адрес в LAN. С облачной ВМ ping даёт 100% потерь. Нужен **локальный** Cursor Agent на Mac или этот скрипт в Terminal.
