# Сигнал

SEO-сайт студии: создание сайтов, доработка и SEO-продвижение.

- Next.js App Router (SSG)
- Хабы категорий и статьи под семантическое ядро
- JSON-LD, sitemap, robots, ЧПУ
- Генератор черновиков статей: `npm run generate:articles`

## Локально

```bash
cd webora
npm ci
npm run dev
```
